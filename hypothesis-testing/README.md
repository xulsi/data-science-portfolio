# Hypothesis Testing — Z-test and T-test

## Overview
Complete implementation of statistical hypothesis testing
from theory to Python code, based on Montgomery's
"Design and Analysis of Experiments".

## What the notebook covers
- Z-test (σ known) vs T-test (σ unknown)
- Why T-distribution has heavier tails than Normal
- One-tailed vs Two-tailed tests
- When to reject H₀ — decision rules
- Visual comparison of all cases

## Key Results
- p(one-tail) = p(two-tail) / 2
- T-distribution converges to Normal as ν → ∞
- Same t₀ can lead to different decisions depending on test type

## Connection to real world
Direct application to industrial quality control,
A/B testing, and model comparison — all common tasks
in data analyst roles.
